# Roadmap

Direction for community work, not a delivery promise or completed achievements.

## Near-term

- End-to-end tests for EPUB import, floating notes, flashcard conversion and reopening.
- More mobile, keyboard and screen-reader checks; better focus behavior.
- Resolve legacy lint and standalone TypeScript findings without hiding them.
- Extract reader orchestration into smaller, tested modules.
- Improve English documentation and document browser-specific speech/folder behavior.

## Before broader public hosting

- A reviewed authentication/session layer independent of Sites headers.
- Upload constraints, request quotas and AI-spend controls for shared hosting.
- More cross-account isolation, offline conflict and concurrent recovery tests.
- Deployment instructions independent of the maintainer's private environment.

## Study workflow

- Better review statistics and scheduling transparency.
- Optional board grouping and tags.
- Evaluate flashcards and citations against an openly redistributable test corpus.

Useful contributions are reproducible reports, small tests and reviewed fixes. Describe adoption and impact using real evidence, not invented counts or promised outcomes.
